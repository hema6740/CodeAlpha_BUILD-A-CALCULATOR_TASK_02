# 🧮 Basic Calculator – CodeAlpha Internship Task 2

This project is a **simple and responsive Calculator** built using **HTML, CSS, and JavaScript**.  
It supports all arithmetic operations and includes real-time display updates and keyboard input.

---

## 🚀 Features

### ✔ 1. Basic Arithmetic Operations
The calculator can perform:
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)

### ✔ 2. Interactive User Interface
- Clean layout with clickable buttons  
- Large display screen for input and results  
- Smooth button animations  

### ✔ 3. Real-Time Result Handling
- Shows input as you type  
- Displays calculated result instantly  
- Handles errors (like division by zero)

### ✔ 4. Functional Buttons
- **AC (All Clear)** → clears entire display  
- **DEL (Backspace)** → deletes last digit  
- **= (Equals)** → evaluates expression  

### ✔ 5. Keyboard Support (Bonus)
- You can type numbers directly  
- Use `Enter` to calculate  
- Use `Backspace` to delete  
- Supports operators (+, -, *, /)

### ✔ 6. Responsive Design
- Works on desktop, tablet, and mobile  
- Buttons adjust based on screen size
